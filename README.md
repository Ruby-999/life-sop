# 今日节律 · Life SOP

把日常 SOP 锚定到日历上的个人生活节律工具。今天的每一杯水、每一次勾选，都被记进日历里。

## 功能

- **今日页**：周历条 + 圆环完成度 + 每日打卡 + 周期触发事项（按周 / 按天自动铺排）
- **月历页**：整月视图，有数据的日期用进度圆环框住，点日期查看当日清单与完成度
- **规则库**：个人卫生 / 居住环境 / 换新 / 健康 四大分类的 SOP 规则管理
- **我（ME）**：自定义背景图片（含透明度调节与预设渐变）、毛玻璃外观模式、自定义头像、随机鼓励语
- **饮水打卡**：每 500ml 一格（共 3 格），超出 1500ml 用额外颜色显示
- **饮料记录**：拍照 / 上传记录饮品，估算热量与糖分，月历绿色标注便于控量
- **主题色系统**：从背景图自动提取主色，整套 UI 的强调色随之变化
- **激励反馈**：勾选粒子爆开 + `+1` 飘字 + 进度环脉冲，当日全达成触发全屏彩纸雨

## 使用

### 直接打开

浏览器打开 `index.html` 即可使用，无需构建、无需依赖安装。

### 安装到手机（PWA）

部署后访问站点地址：

- **iPhone / Safari**：分享 → 添加到主屏幕
- **Android / Chrome**：菜单 → 安装应用

安装后为独立窗口全屏运行，支持离线访问（Service Worker 缓存）。

## 本地预览

```bash
# 任意静态服务器即可，例如
python -m http.server 3000
```

然后访问 <http://localhost:3000>。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 应用主体（单文件：结构 + 样式 + 逻辑 + 数据） |
| `manifest.json` | PWA 清单：应用名、图标、独立窗口模式、快捷入口 |
| `sw.js` | Service Worker：离线缓存与导航回退 |
| `icon.svg` | 矢量源图标 |
| `icon-192.png` / `icon-512.png` | PWA 标准图标 |
| `icon-maskable-512.png` | Android 自适应图标（含安全边距） |
| `apple-touch-icon.png` | iOS 桌面图标（180×180） |

## 数据存储

所有数据保存在浏览器 `localStorage`，不经过任何服务器：

| 键名 | 内容 |
|---|---|
| `sop_userBg` | 自定义背景图（压缩后的 data URL） |
| `sop_userBgOpacity` | 背景透明度 |
| `sop_userBgPreset` | 选中的预设渐变 |
| `sop_userBgAccent` | 从背景图提取的主色缓存 |
| `sop_userGlass` | 毛玻璃模式开关 |
| `sop_userAvatar` | 自定义头像（压缩后的 data URL） |
| `sop_*` | 饮水、饮料、打卡、周期事项等状态 |

> 数据存在本地浏览器中，换浏览器或清除站点数据会重置。

## 部署
